Sometimes I feel like there's an app for everything.

Tasks. Emails. Customers. Sales. Graphics. Reminders. Automation.

At this rate, we'll soon need an app to remember the passwords for all the apps managing our other apps. 😅

I'm joking, but only partly.

When you're trying to grow a small business, it's easy to go looking for the perfect tool. The hope is that it will create order for you.

Spoiler: **software can't choose your priorities**.

## What I want from a tool

Before adding another app, I try to answer three simple questions.

What specific problem does it solve?

Will I actually use it every week, or only while the new-tool excitement lasts?

And can I get my data back if I leave?

A service that's easy to start using but hard to leave can become expensive over time.

## A small setup is often enough

For a young business, I would focus on a few basic needs:

- **Communicate**: professional email and a reliable way to find past conversations.
- **Plan**: a calendar and a task list people actually look at.
- **Follow up with customers**: a simple CRM or spreadsheet with leads and next actions.
- **Manage money**: quotations, invoices, expenses and payment records.
- **Store documents**: shared files, sensible permissions and backups.
- **Create and publish**: tools that fit the content you actually produce.

Not everything needs an expensive all-in-one suite from day one.

## What about AI?

An AI assistant can save time summarising documents, outlining ideas, drafting a first version or exploring options.

That's useful. I use these tools in my own work too.

But numbers need checking, sensitive information needs protecting and someone still needs to make the final decision.

**Automating a useless task doesn't make it valuable.**

So the right question isn't “Which AI agent should I install?” It's “Which repeated task is genuinely worth simplifying?”

## Don't mistake organisation for decoration

You can spend a whole day customising a dashboard: colours, icons, columns, automations.

By evening, it looks fantastic.

The problem is that you still haven't called back the customer who's been waiting since Tuesday. 🙃

A good tool should reduce that sort of friction, not create another full-time job.

## My minimum-useful rule

I'd rather start with a few tools, use them consistently and change only when a real need appears.

If a workflow becomes too complex, I look at the workflow before paying for another service.

And when I'm unsure, I return to a very practical question: **will this help me serve customers better or manage my time better?**

If the answer is vague, I probably have something else to do.

Like finishing that project still waiting in my code editor.
